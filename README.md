# OpenMPTCProuter Server admin rest API

The OpenMPTCProuter API is based on [FastAPI](https://fastapi.tiangolo.com/).

## Documentation

- [API reference](docs/api.md) — authentication, permissions and all endpoints
- [Decision engine](docs/omr-decision-engine.md) — metrics collection and WAN weight learning (`omr_metrics`)

An interactive Swagger UI is also available on a running server at `/docs`
(log in first via `/login_basic`).
